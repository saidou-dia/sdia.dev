# Saidou DIA — Portfolio

A responsive, static HTML/CSS/JavaScript portfolio for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — Dark Tech responsive design
- `script.js` — mobile navigation and current footer year
- `CNAME` — custom domain for GitHub Pages

## Publish on GitHub Pages
1. Review the content and links in `index.html`.
2. Upload/replace `index.html`, `style.css`, `script.js` and `CNAME` in the root of the `main` branch of `saidou-dia/sdia.dev`.
3. Keep the repository's GitHub Pages source configured to deploy from `main` / root.
4. In Settings → Pages, confirm the custom domain is `sdia.dev` and HTTPS is enabled.
5. Open `https://sdia.dev` after deployment.

The portfolio uses no build step or package installation. Google Fonts are optional; system fonts remain as fallbacks.
